# Digital Notebook
**Web Systems and Technology Project**

A simple web-based notebook application built with **HTML, CSS, JavaScript, and Node.js (Express)**.  
It allows users to create subjects, switch between them, and save notes in two text areas (left and right).  
Subjects can be renamed or deleted using a right-click context menu. Notes are stored in `backend/subjects.json`.

---

## ✨ Features
- Create multiple subjects with custom names
- Save notes in two separate text areas per subject
- Switch between subjects easily
- Rename or delete subjects via right-click menu
- Notes are preserved when switching subjects
- Auto-save while typing (no need to switch subjects to save)

---

## 🚀 How to Run
1. Clone the repository:
   git clone <repo-url>
   cd Digital-Notebook
2. Install dependencies:
   npm install express
3. Start the backend server:.
   node backend/app.js
4. Open the notebook in your browser:
   http://localhost:3000/
